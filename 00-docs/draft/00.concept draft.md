

# EyeG-XXX構想

## なにを
* GoogleKeepのようなメモアプリの拡張版のイメージ
* スマホ向けWEBアプリ

## 概略
* KeepのAPIが非公開なので自力でAPIも実装する
* 2XXX
  * メモした日時、メモ文、写真4枚まで、GPS位置情報、私用/仕事用/一般のカテゴライズ、重要度、期限、をさっとメモする
* 4XXX
  * メモを簡単に見る
    * 標準ビューでは重みづけをする（重要なものが浮上してくるUX）
      * カテゴリ、重要度、期限
      * 見た時間帯によってカテゴリに重み（日中は仕事優先、週末は私用、など）
      * メモの閲覧回数
      * メモの鮮度（新規である、更新直後である、など）
    * 重み以外のソート・フィルタも実装したい
      * 日付順、カテゴリ別、、、など
  * Googleカレンダー連携
    * 初版リリース時は実装しない
    * 将来構想として
      * EyeG-Cal 経由連携でもいいかもしれない
