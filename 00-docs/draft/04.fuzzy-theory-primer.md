# ファジィ理論 解説 — EyeG-Stack 重みづけへの応用ガイド

03.weight-algorithm.md（v1.1）でファジィ理論の考え方を採用した。本書は、実装・チューニング・将来拡張の判断に必要な範囲でファジィ理論を解説する社内向けプライマーであり、教科書的な網羅は目的としない。

引用はすべて J-STAGE で無料公開されている論文抄録からの原文引用（出典・DOI明記）。本文PDFも各リンク先から無料で読める。

## 1. ファジィ集合とメンバーシップ関数

古典的な集合（crisp 集合）では、要素は集合に「属する(1)か属さない(0)か」の二値で決まる。ファジィ集合（Zadeh, 1965）はこれを一般化し、**属する度合い**をメンバーシップ関数 μ: X → [0, 1] で表す。

- crisp: 「18:00 以降は夜である」→ 17:59 は昼(1)、18:00 は夜(1)。境界で世界が反転する。
- fuzzy: 「18:00 ごろから夜になっていく」→ μ_夜(17:45) = 0.25、μ_夜(18:15) = 0.75。境界がなだらか。

代表的な関数形は**三角形・台形・シグモイド**。EyeG-Stack の μ_昼（03 の S_cat）は台形を採用している。

**EyeG-Stack ではすでに至るところにある**: 0〜1 に正規化した各スコアはすべてメンバーシップ関数として読める。S_due は「期限が近い」というファジィ集合への所属度、S_fresh は「新しい」への所属度。v1 の時点で設計は半分ファジィ的だった、というのが正確な理解。

**確率との混同に注意**: μ_昼 = 0.7 は「70% の確率で昼」ではなく「0.7 の度合いで昼っぽい」。確率は不確実性（どちらかわからない）、ファジィは曖昧性（境界がそもそもぼやけている）を扱う。重みづけに使っているのは後者。

## 2. ファジィ論理演算 — t-ノルムと t-コノルム

度合い同士の AND / OR をどう計算するか。その一般化が **t-ノルム**（AND）と **t-コノルム**（OR）。

t-ノルム T(a, b) は次の公理を満たす [0,1]² → [0,1] の関数: 可換律 T(a,b) = T(b,a)、結合律、単調性、単位元 T(a, 1) = a。

| 名称 | t-ノルム（AND） | 対応する t-コノルム（OR） | 性格 |
|------|----------------|--------------------------|------|
| Zadeh（min/max） | min(a, b) | max(a, b) | 弱い方／強い方だけ見る。相乗効果なし |
| 代数積 | a × b | a + b − ab | 滑らか。両方の値が常に効く |
| Łukasiewicz | max(0, a + b − 1) | min(1, a + b) | 厳しい AND。両方高くないとゼロに落ちる |

数値例（a = 0.8, b = 0.6）: min → 0.6 / 積 → 0.48 / Łukasiewicz → 0.4。同じ「AND」でも選ぶ演算で結果が変わる。否定は標準的に N(a) = 1 − a。

**どの t-ノルムを選ぶかは設計判断**であり、ここが河口先生の研究領域の核心に当たる。t-ノルムの選択が結果の曖昧さを制御するという視点は、同氏の論文抄録に明確に表れている:

> この算法においては, t-ノルムの選択によって曖昧さを積極的に制御することができるのが, 最大の利点である.
> — 河口万由香・伊達惇「t-ノルムに基づくファジィ算法に関する諸性質」日本ファジィ学会誌 5(5), 1993（抄録より） https://doi.org/10.3156/jfuzzy.5.5_1113

同論文はさらに、t-ノルムに基づく演算の代数的性質（単位元・可換性・結合性など）を一般的に考察し、「ファジィ数は, t-ノルムに基づく加法・乗法に関して単位的可換半群をなす」（同抄録）ことを示している。演算を場当たり的に選ぶのではなく、公理を満たす族の中から性質を見極めて選ぶ、という姿勢がファジィ理論の流儀。

**EyeG-Stack への含意**: 将来「期限が近い AND 重要」の相乗ルールを足す場合は**代数積**を推奨する。min は片方の値の変化を無視する区間が生まれ、Łukasiewicz は中程度同士（0.6 と 0.5 → 0.1）をほぼ殺してしまう。積は両方の変化が常に滑らかに反映され、チューニングの見通しが良い。

## 3. ユニノルム — 正負両方向の証拠を混ぜる演算

t-ノルムの単位元は 1（= AND 的）、t-コノルムは 0（= OR 的）。**ユニノルム**はその一般化で、単位元 e を (0, 1) の内部に持つ。e より上の値同士は強め合い、下の値同士は弱め合い、上と下が混在すると打ち消し合う — つまり**中立点を挟んだ双極的な証拠の合成**ができる。

河口先生らはこのユニノルムを論理体系として定式化する研究を行っている:

> MTL(monoidal t-norm based logic)より弱いファジイ論理として，部分構造論理の観点から構造規則weakeningを制限することにより，ファジィ論理ULを定式化した．
> — 亘理修・河口万由香・宮腰政明「ユニノルムに基づくファジィ論理と構造規則」第22回ファジィシステムシンポジウム, 2006（抄録より） https://doi.org/10.14864/fss.22.0.193.0

**EyeG-Stack への含意**: S_man（手動順位操作）は up と down という正負両方向の証拠を中立点 0 を挟んで合成する、本仕様で唯一の双極的要素であり、構造がユニノルムの世界観と一致する。現行の tanh((up−down)/5) はその実用的簡易形。将来、複数の双極的シグナル（例: ピン留め/ミュート等）が増えて合成則が必要になったら、ユニノルムが理論的な参照先になる。

## 4. ファジィ推論 — Mamdani 型と TSK 型

ファジィルール「IF x is A THEN y is B」の集まりから出力を得る方法は大きく2系統ある。

- **Mamdani 型**: 後件（THEN 側）もファジィ集合。各ルールの結論をファジィ集合のまま合成し、最後に**脱ファジィ化**（重心法など）で1つの値に潰す。表現力は高いが計算と設計が重い。
- **TSK 型（Takagi–Sugeno）**: 後件を関数（**0次なら定数**）にする。出力は各ルールの適合度 μ_i による加重平均 `y = Σ μ_i·c_i / Σ μ_i`。脱ファジィ化が不要で軽く、挙動が読みやすい。

**EyeG-Stack の S_cat は0次 TSK の最小形**である。ルールは実質2本:

```
IF 時刻 is 平日昼 THEN s_cat = 表[平日昼][カテゴリ]
IF 時刻 is 平日夜 THEN s_cat = 表[平日夜][カテゴリ]
出力 = μ_昼·c_昼 + μ_夜·c_夜   （μ_昼 + μ_夜 = 1 なので分母は常に 1）
```

Mamdani 型を採らない理由は EyeG 思想（シンプル・説明可能・コストゼロ）。脱ファジィ化を持ち込むと係数チューニングの直感が壊れ、得られる滑らかさは TSK と大差ない。

## 5. ファジィルールベースとルール補間

ルール表が入力空間を覆いきれていない（疎な）とき、観測がルールとルールの「間」に落ちたらどうするか — 隣接ルールから答えを**補間**する、というのがルール補間の研究領域で、河口先生の応用面の代表テーマのひとつ（「欠損のあるファジィルールベースにおけるルール補間」FSS 2008、"Fuzzy Spline Interpolation in Sparse Fuzzy Rule Bases" World Scientific, 2001 ほか）。

**EyeG-Stack への含意**: 時間帯×カテゴリのルール表は 3×3 で密だが、v1.1 の遷移帯は「境界をまたぐ時刻ではルール間を線形補間する」処理であり、**ルールを増やさずルールの間を埋める**というルール補間と同じ精神。将来ルール表を細分化（朝・昼・夕・夜など）しても、この補間の枠組みのまま拡張できる。

## 6. EyeG-Stack における採用範囲まとめ

| 概念 | 採用状況 | 対応箇所 |
|------|----------|----------|
| メンバーシップ関数 | **採用済み** | 全スコアの 0〜1 正規化、μ_昼（台形） |
| 0次 TSK 合成 | **採用済み（v1.1）** | S_cat の時間帯ブレンド |
| ルール間の補間 | **採用済み（精神として）** | 遷移帯 CAT_BLEND_MIN |
| t-ノルム（相乗ルール） | 将来候補 | 「期限近い AND 重要」等。採用時は代数積を推奨 |
| ユニノルム | 将来候補（理論参照） | S_man の双極合成の定式化 |
| Mamdani 推論・脱ファジィ化 | **不採用** | 複雑さに見合う利得がない |
| Type-2 ファジィ | **不採用** | メンバーシップ自体の曖昧さまで扱う発展形。本用途には過剰 |

判断基準は一貫して「**まず crisp で考え、不連続が体験を損ねる場所だけファジィ化する**」。ファジィ化は目的ではなく、ジャンプを消す道具。

## 7. チューニングの勘どころ

- **遷移帯の幅（CAT_BLEND_MIN）**: 広げるほど滑らかだが時間帯のメリハリが減る。60分（±30分）が初期値。体感で 30〜120 分の範囲を探る。
- **関数形**: 台形（線形クロスフェード）で十分。さらに滑らかにしたければシグモイド形もあるが、視認できる差はほぼ出ない。
- **ルール表の値**: TSK の後件定数はそのまま「その時間帯でそのカテゴリをどれだけ優先するか」。迷ったら表の値を直接いじるのが最も説明可能なチューニング。
- **相乗ルールを足すとき**: 1本目は係数 0.05〜0.10 の小さな追加項として入れ、既存6要素の係数バランスを崩さないこと。
