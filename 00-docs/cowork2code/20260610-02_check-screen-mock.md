# Check画面 モック作成指示

## 目的

EyeG-Stack の Check（メモ閲覧）画面のHTMLモックを作成する。
API連携は不要。ダミーデータを使って見た目とUXの確認が目的。

## 参照

- デザイン基盤: Push画面モック（`01-mock/push/index.html`）のCSSを流用・統一すること
- カラートークンはPush画面と同じ仮色を使う
- レイアウト構造（`.eyeg-app` / `.eyeg-header` / `.eyeg-main` / `.eyeg-actions`）はシリーズ共通で踏襲する

## 画面構成

### ヘッダー

Push画面と同じ構造を踏襲する。

- 左: メニューへ（グリッドアイコン）、Push へ（ナビリンク）
- 中央: アプリ名「EyeG-Stack」＋バージョン
- 右: アバター（ダミー）

### ソートタブ

ヘッダー直下に横並びのタブを配置。

| タブ名 | 説明 |
|--------|------|
| おすすめ | 重みづけ順（デフォルト） |
| 新しい順 | 作成日時の降順 |
| カテゴリ | 私用 / 仕事用 / 一般 でグループ表示 |

- デフォルト選択: おすすめ
- モックでは各タブで異なるダミーデータ順を表示するだけでよい

### メモ一覧

各メモをカード形式で縦に並べる。

**1件あたりの表示内容:**

- メモ文（必須）。長い場合は3行程度で省略（`line-clamp`）

カテゴリ・重要度・期限・日時などはカード上には表示しない（シンプルさ優先）。

### メモタップ時: 詳細モーダル

メモカードをタップすると、下からスライドアップするモーダルで詳細を表示する。

**モーダルの表示内容:**

- メモ文（全文）
- カテゴリ
- 重要度（設定があれば）
- 期限（設定があれば）
- 作成日時
- （写真スロット: ダミーでよい）

**モーダルのアクション（フッター）:**

- **閉じる**（ghost）
- **編集**（ghost、遷移先は未実装のためダミーでよい）
- **削除**（danger、confirm モーダルを挟む）

### Push ボタン

画面右下にフローティングの「＋」ボタンを配置し、`../push/index.html` へ遷移する。
（Check 画面からも手軽に Push できる導線として）

## 手動順位操作

### 操作方法

- メモカードを**長押し**すると、カードが浮いた状態になりドラッグ可能になる
- ドラッグして離した位置に応じて、動かした段数分だけカウントに加算する
  - 例: 3つ上に動かした → `manual_up_count += 3`
  - 例: 2つ下に動かした → `manual_down_count += 2`
- ドラッグ中は他のカードがスライドして隙間を作るアニメーションを表示する
- 離した後、カードは新しい位置に収まり、一覧が再描画される

### モックでの実装方針

- HTML5 の `draggable` またはタッチイベントで実装する
- カウントの増減はダミーデータの `manual_up_count` / `manual_down_count` に反映し、「おすすめ」タブの並び順に即時反映されるようにする（簡易的な重みづけ再計算でよい）
- 長押し判定は `setTimeout` 500ms 程度で実装する
- 浮いた状態はカードに `opacity: 0.8` + 軽い `scale` で視覚的に表現する

## UX方針

- **一覧はシンプルに**: メモ文だけ見えればよい。情報を詰め込まない。
- **詳細はモーダルで**: タップで気軽に開け、背景タップで閉じられる。
- **Push への導線を切らない**: フローティング「＋」ボタンで常にPushへ戻れる。
- タップターゲットは44px以上を厳守。
