## 指示通りの実施内容

### 画面構成

- **ヘッダー**: 左にアプリ名「EyeG-Stack」、右にダミーアバター（イニシャル「ES」）。
- **メモ文**: `textarea`、3行分の高さ、プレースホルダー「メモを入力…」、`autofocus`。
- **カテゴリ**: 私用 / 仕事用 / 一般の横並びトグル。デフォルト「私用」。
- **オプションエリア**: 「+ 詳細」ボタンで展開（初期は折りたたみ）。
  - **重要度**: 1〜5のスター（タップで点灯、同値再タップで解除）。
  - **期限**: `<input type="date">`。
  - **写真**: 最大4枚のダミーグリッド。
- **GPS**: UIには出さず、フッター付近に「GPS取得中…」ステータスのみ小さく表示。
- **アクション**: 画面下部に固定した primary な Push ボタン。

### UX方針

- 開いたらすぐ入力できる状態（メイン2項目は常時表示、`autofocus`）。
- オプションはデフォルト非表示。
- メモ文が空でも Push 可能（バリデーションなし）。
- タップターゲットは全て 44px 以上。

### デザイン基盤

- `eyeg-cal/shared/eyeg.css` から必要部分をコピペ移植し、`<style>` に取り込んで
  単一ファイルで自己完結させた。
- カラートークンは EyeG-Stack 独自の仮色を `:root` で上書き。

## 指示外の追加判断（対話で確定）

着手後の対話で、かきざきさんと協議のうえ以下を追加・変更した。すべて承認済み。

### 1. CSS は `<link>` 参照ではなくコピペ移植で自己完結

**経緯:** 指示書では `eyeg-cal/shared/eyeg.css` の `<link>` 相対参照（`../../eyeg-cal/shared/eyeg.css`）も可とされていた。

**決定:** eyeg-cal は読み取り専用の外部参照であり、モックが将来 EyeG-Stack
単体で扱われる可能性を考え、必要部分のみコピペ移植して単一ファイルで自己完結
させた（「必要なコードのみコピペ移植を許可」の方針に沿う）。

### 2. テーマカラーを「青緑（ビリジアン系）」に確定（仮）

**経緯:** 指示書の例 `--eyeg-bg-light: #0F6E56` は 4Cal の `#0F6E78`（ティール）と
酷似しており、core.md の「他アプリと異なる独自カラー」方針に反していた。

**決定:** シリーズ内の hue 配置を確認のうえ、2Cal=青(212°) / 4Cal=ティール(186°)
の中間 hue≈195° の青緑に置いた。色味の方向性はかきざきさんと複数回すり合わせ。

| トークン | 値 |
|----------|-----|
| `--eyeg-bg-light` | `#0B6985` |
| `--eyeg-bg-dark` | `#053848` |
| `--eyeg-accent-light` | `#84D2E6` |
| `--eyeg-accent-mid` | `#1F9CC4` |
| `--eyeg-accent-dark` | `#136080` |

あくまで**仮の独自色**。正式なテーマカラーは未定（TBD）のままで、`:root` の
5トークンを差し替えれば反映される。

### 3. ヘッダーに「メニューへ」「Check へ」ナビを追加

**経緯:** 指示書のヘッダー仕様はアプリ名とアバターのみ。eyeg-cal の
`.menu-back` パターンに倣ったナビ導線が欲しいとの要望。

**決定:** EyeG-Cal の `.menu-back`（丸ピル型）を流用し、以下2つを追加。
EyeG-Cal との相互遷移は想定しないため、遷移先は EyeG-Stack 内に閉じる。

- **メニューへ**（グリッドアイコン）: `index.html`（EyeG-Stack メニュー想定。
  Push / Check のみに遷移する自前メニュー）
- **Check へ**: `check.html`（Push の対となる閲覧機能）

いずれも遷移先は未実装のため、モックではパスのみ仮置き。

### 6. モックは `01-mock/` 直下のフラット構成に

**経緯:** これから Check・メニューのモックも作るにあたり、当初の
`01-mock/push/index.html`（フォルダ分け）から相対リンクの取り回しを見直した。

**決定:** `01-mock/` 直下にフラットに並べる。`index.html`（メニュー）/
`push.html` / `check.html` を相対 href で相互遷移させる（index ↔ push ↔ check）。
本フィードバック作成時点では `push.html` のみ実装済み。

### 4. バージョン表記をヘッダーに追加

タイトル右に `v0.1.0` を小さく表示（4Cal の `.app-version` を踏襲）。

### 5. Push 確認を独自 confirm モーダルに

**経緯:** 指示書では「アラートなどでフィードバックを返せばよい」とされていた。

**決定:** ネイティブ `alert/confirm` ではなく、EyeG-Cal の `EyeG.confirm()` を
移植したテーマ統一モーダルで確認を取る形にした（Promise ベース、背景クリック /
Esc でキャンセル、Enter で確定）。確認 → 確定後に「Push しました（モック）」の
完了モーダルを表示。
